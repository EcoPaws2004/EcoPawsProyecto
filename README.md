## 📖 2. Sobre el Proyecto

**EcoPaws** es una aplicación móvil pensada para brindar apoyo a perritos en situación de calle. Esta herramienta está enfocada en facilitar el **rescate y reporte de perros abandonados**, especialmente en zonas donde hay una **gran acumulación de basura**, lo cual representa un foco importante de riesgo y proliferación de animales sin hogar.  
La app también permite **reportar perritos desaparecidos** y **perritas en celo**, con el objetivo de intervenir antes de que estos casos se vuelvan críticos. EcoPaws nace con la intención de conectar a la comunidad con recursos y herramientas que ayuden a mejorar las condiciones de vida de estos animales, brindando visibilidad, acción rápida, y esperanza a los que no pueden pedir ayuda por sí mismos.

## 🎯 4. Propósito del Proyecto

El propósito principal de **EcoPaws** es tenderle una mano —o una pata— a todos aquellos perritos que enfrentan situaciones adversas como el abandono, la desnutrición, la falta de atención médica, o simplemente el olvido.  
Esta app busca convertirse en una herramienta útil y accesible para **personas solidarias** que quieran ayudar, brindando una plataforma confiable para reportar, registrar y difundir casos. Al facilitar la conexión entre voluntarios, rescatistas y la comunidad, EcoPaws tiene como meta contribuir significativamente a que estos animalitos tengan una **vida más digna, protegida y amorosa**.

## 📁 7. Estructura de Archivos

La aplicación está organizada en carpetas según el siguiente esquema:

- **`auth/`**: Contiene las pantallas relacionadas con el inicio de sesión y el registro de usuarios.
- **`main/`**: Aquí se encuentra la pantalla principal o menú desde donde se accede al resto de funcionalidades.
- **`pages/`**: Incluye todas las demás páginas de la app, como reportes de casos, perfil de usuario, notificaciones, y estadísticas.
- **`services/`**: Contiene los servicios que manejan la lógica de autenticación, como el inicio y cierre de sesión.
- **`environments/`**: Archivos con la configuración necesaria para conectarse a la base de datos de Firebase, incluyendo claves y URLs de entorno.

## 📌 9. Sobre Su Proyecto

Actualmente, el proyecto **EcoPaws** ya cuenta con funcionalidades básicas y en funcionamiento. El sistema de **registro e inicio de sesión está operativo**, permitiendo a los usuarios acceder de forma segura.  
Además, ya es posible **realizar reportes**, los cuales se almacenan correctamente en la base de datos de Firebase. La app también es capaz de **consultar y recuperar esos reportes** para que otros usuarios puedan visualizar situaciones ya documentadas y actuar en consecuencia. Esta base funcional sienta las bases para seguir ampliando las capacidades de la aplicación en futuras versiones.
